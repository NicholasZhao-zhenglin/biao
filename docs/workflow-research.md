# 投标文件从读标到递交的工作流调研

本次以中国政府采购货物和服务项目的供应商为目标用户，核对了公开的交易平台操作手册、实际招标文件和产品资料。下面的流程来自资料分析与样本实测，市场产品功能来自厂商公开说明。

| 工作环节 | 一手资料中的操作 | 标衡中的对应操作 |
| --- | --- | --- |
| 读标与拆解 | 招标文件把资格、评分方法、采购需求、文件格式放在不同章节，有些条款带勾选条件或引用项目资料表。 | 从一份招标文件立项，按章节整理候选条款，保留原文和 PDF 页码，人工补录与判定适用性。 |
| 编制与取证 | 新点的制作指南要求将评分点对应到投标文档的具体位置；内蒙古供应商手册要求标记应答起止位置。 | 在同一条款记录负责人、章节、响应、证明材料与位置，从已导入的投标正文找候选摘录。 |
| 复用与复核 | Loopio 的产品演示把检索材料、分配给专业人员、整理并导出响应放在同一条工作流中。筑龙标事通把招标解析、响应检查和清标列为不同功能。 | 按条款编写和复核；资料维护、条款状态、原文依据以及最终上传版本的规则或 AI 审核分别有明确位置。 |
| 更正与交付 | 地方平台的操作手册包含文件生成、签章、加密及上传，具体操作取决于所用平台。 | 本机工作台导出可编辑响应稿与内部矩阵。经办人再按项目模板排版，在指定客户端签章、加密并递交。 |

参考资料包括 [新点电子交易平台《投标文件的制作与上传指南》](https://enshi.etrading.cn/bszn/015002/015002001/20220817/401a2e2a-f203-4389-ac54-15fa15851785.html)、[内蒙古政府采购电子化交易系统供应商手册第 15–18 页](https://www.ccgp-neimenggu.gov.cn/gpx-bid-file/150101/gpx-tender/2023/7/21/402881cc893faf4a01897810cdaa31c2.pdf?accessCode=eb96e08e58b981ce39c50b4406e41261)、[Loopio 产品演示](https://loopio.com/demo-tutorial/) 和 [筑龙标事通产品说明](https://www.biaoshitong.com/bidDoc)。

## 真实文件走查

选取北京市水务局公开的北京市水科学技术研究院《网络与信息系统运行维护服务》招标文件。该文件共 99 个 PDF 页面。复现时从原发布地址下载 PDF，选择“新建项目”，仅导入招标文件，进入矩阵后用以下关键词搜索并查看原文。仓库内置项目另用虚构资料编写。[公开招标文件 PDF](https://swj.beijing.gov.cn/zwgk/zfcg/zbcjgg/202505/P020250527642307970311.pdf)

| PDF 文件页序 | 抽查内容 | 经办人要做的判断 |
| --- | --- | --- |
| 3 | 最高限价 129.5975 万元 | 确认价格口径和所投标包。 |
| 4 | 截止时间为 2025 年 5 月 27 日 09:30 | 核实是否另有更正公告。 |
| 8 | 投标有效期 90 日历天，另列正副本及电子版数量 | 分别落实商务承诺及文件制作。 |
| 24、26 | 营业执照及授权委托书相关要求 | 选择适用的主体情形，绑定实际证明材料。 |
| 32 | 应用软件维护方案的分档评分 | 逐档核查方案依据；提取到评分文字本身不能证明已经得分。 |
| 39 | 维护内容表 | 多列或跨行单元格经文本提取可能发生粘连，应对照原件修正。 |

此次从原文件识别出 443 个候选条款。逐项核对字符范围，443 个候选均能定位至提取正文。这个数量包含通用须知和模板里的候选，不能视作 443 项独立义务，也不能用于估计对其他项目的召回率。工作台保留人工补录、复核及导出矩阵的入口。

在独立浏览器会话中，实际填写了限价条款的负责人、证明位置和响应，标记已复核后刷新，四项均保留。随后导出并核对了 CSV 和 Word。另用测试副本模拟限价更正，新金额重新进入矩阵，旧条款的草稿和负责人保留并进入待重定位状态。该更正仅用于测试，与采购方发布的原文件无关。

## 产品取舍

这一版优先支持经办人在本机准备和复核一个标段，并用 CSV、Word 和项目备份完成交接。负责人是工作分工记录。多人实时同步、组织权限、影像 OCR、签章有效性验证和电子递标均需另行系统支持。实际投标须使用本项目指定的文件格式并核对最新澄清。
